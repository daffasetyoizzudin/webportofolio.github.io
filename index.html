Daffa Setyo

Halo! Nama saya Daffa Setyo, seorang mahasiswa aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro. Saya memiliki minat besar dalam pengembangan aplikasi web, perancangan basis data, serta analisis sistem informasi. Saya senang mempelajari teknologi baru yang dapat membantu menyelesaikan berbagai tantangan di bidang teknologi informasi.

Halaman portofolio ini dirancang menggunakan HTML5 terstruktur serta CSS modern yang responsif untuk berbagai ukuran layar. Pembuatan halaman ini menjadi salah satu sarana penting untuk memantapkan pemahaman dasar pengembangan web sebelum melangkah ke pembuatan sistem yang lebih kompleks.
